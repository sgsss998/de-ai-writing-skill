# DeAI-Writing-Skill

**English | [简体中文](README.zh-CN.md)**

![de-ai-writing-skill cover](./cover-de-ai-writing-skill-v1.png)

A small, copy-paste **Agent Skill / system prompt** pack to make LLM drafts read less like “AI slop”: fewer stacked headings, longer flowing paragraphs, concrete detail first, honest tone—closer to how people actually write.

Companion to **[AI-Word-Skill](https://github.com/sgsss998/AI-Word-Skill)** (preserve Word layout when editing). This repo is about **wording and rhythm**, not document structure in Word.

## Why this exists

Default model behavior is often **top-down**: outline first, then evenly spaced short paragraphs and connector phrases (“Firstly… Secondly… In conclusion…”). That reads “correct” but fake.

This skill nudges **bottom-up** writing: scenes, judgments, and messy human rhythm; structure can show up later.

## How to use

1. Copy [`docs/SKILL.zh-CN.md`](docs/SKILL.zh-CN.md) or [`docs/SKILL.en.md`](docs/SKILL.en.md) into:
   - Cursor **Rules** / project instructions, or   - A **Skill** description, or  
   - A one-off system block before your task.
2. Optionally add **your own** reference pieces under [`examples/`](examples/) and mention them in your local rules—**without editing** the exemplars inside `docs/SKILL.zh-CN.md`.

---

## Repo name note

`remove-ai-skill` is easy to misread as “anti-AI.” This repo is **`de-ai-writing-skill`**: *de-AI flavor in writing*, not removing AI from your workflow.
