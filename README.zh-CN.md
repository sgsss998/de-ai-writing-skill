# DeAI-Writing-Skill（去 AI 味写作 Skill）

**[English](README.md) | 简体中文**

一套可复制粘贴的 **Agent Skill / 系统提示**：让模型少写「小标题 + 短段 + 连接词表演」，多写**具体细节、长段流动、坦诚语气**，读起来更像人写的初稿。

与 **[AI-Word-Skill](https://github.com/sgsss998/AI-Word-Skill)** 并列：**AI-Word-Skill** 管 Word 里怎么改才不掉版式；**本仓库**管模型**怎么写**才不像 AI 腔。可叠加使用。

---

## 一句话

把 [`docs/SKILL.zh-CN.md`](docs/SKILL.zh-CN.md) 整段放进 Cursor 规则、自定义指令或 Skill 描述即可。英文精简版见 [`docs/SKILL.en.md`](docs/SKILL.en.md)。

## 触发示例

- `用去 AI 味风格写作`
- `去除 AI 味道，像人一样写`
- `自下而上：先细节与判断，结构后浮现`

## 为什么叫 `de-ai-writing-skill` 而不是 `remove-ai-skill`

`remove-ai-skill` 容易被理解成「反 AI」或「不用 AI」。本仓库只做一件事：**去掉写作里的 AI 腔**，不反对用模型辅助。
